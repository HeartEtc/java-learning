# Java 纯文字学习路线（不依赖视频）

> 更新日期：2026-09-14
> 前提：不喜欢看视频，偏好 learncpp.com 那种「长文字 + 代码示例 + 练习」的形式。
> 结论：**Java 生态的文字资源比 C++ 更好，纯文字路线完全可行，且更省时间。**
> 唯一代价：文字教程不会逼你动手，必须自己加「强制产出 + 自动判题」两条保险。

---

## 1. 主资源与用途（不要全部读，按用途分工）

| 资源 | 语言 | 用途 | 优先级 |
|---|---|---|---|
| [Dev.java — Learn](https://dev.java/learn/)（Oracle 官方新教程） | 英文 | **主线**，章节短、示例全、持续更新，最接近 learncpp 的阅读体验 | ★★★★★ |
| [Oracle The Java Tutorials](https://docs.oracle.com/javase/tutorial/) | 英文 | 主线备选 / 老牌权威，查"Trail: Learning the Java Language" | ★★★★ |
| 《Java 核心技术 卷 I 开发基础》原书第 12 版 | 中文 | **深度查阅**：构造器、继承、接口、集合、泛型讲得最系统。**不通读** | ★★★★ |
| [CodingBat Java](https://codingbat.com/java) | 英文 | **语法级自动判题**（Warmup / String / Array / Logic），比 LeetCode 更适合大一 | ★★★★★ |
| 廖雪峰 Java 教程 | 中文 | **中文主讲**（W1～W3 面向对象部分），讲得好懂、免费、带在线运行；深度不足处按 §1.1 补 | ★★★★ |
| 《On Java 8》（Bruce Eckel） | 中文 | 进阶补充，**大一不碰**，等 Java SE 学完再回头 | ★ |

**读法（重要）**：**廖雪峰当主讲、Dev.java 或《Java 核心技术》当补深**。判定规则很简单——廖雪峰某一节读完能不能"照着写出代码"，能就继续往下走，不能（或只给了结论没给原理）就翻对应章节。**升级触发条件**：某一节读完仍写不出代码 → 立刻换源，不要反复重读同一页。

### 1.1 廖雪峰的边界（哪些必须换源）

| 主题 | 廖雪峰是否够用 | 处理 |
|---|---|---|
| 面向对象（类/构造器/继承/多态/接口） | 够用，讲得清楚 | 直接当主讲 |
| 集合框架 | 够用（有 ArrayList/HashMap 源码分析小节） | 主讲，但 HashMap 扩容/红黑树要补 |
| 泛型 / Lambda / Stream | 偏薄 | 补 Dev.java 或《Java 核心技术》卷 II |
| IO / NIO | 偏薄 | 补《Java 核心技术》卷 II |
| 多线程、JUC、线程池、JMM | **不够** | 必须换源（《Java 并发编程的艺术》） |
| JVM 内存结构 / GC / 类加载 | **没有** | 换源（《深入理解 Java 虚拟机》） |
| 注解 / 反射 | 有但浅 | 大二再补 |
| 网络编程 | 有基础 | Spring 阶段再深入 |

## 2. 文字路线必须补的两条保险

learncpp 自带编程练习，Java 文字教程多数没有。少了这两条，纯文字会退化成"读得爽、一行没写"。

1. **强制产出**：每读完一节，**代码示例必须手敲一遍**（禁止复制粘贴），当周代码行数 < 200 视为失败。
2. **自动判题**：CodingBat 免费、网页内直接判题、无需环境配置。W1～W4 用它替代部分 LeetCode。
   - 顺序：Warmup-1/2 → String-1/2 → Array-1/2 → Logic-1/2 → AP-1
   - 完成到 **60 题** 后接 LeetCode 数组/字符串简单题。

## 3. 时间分配修订

| 时段 | 原方案 | 现方案 |
|---|---|---|
| 周一～周五 每天 | 视频 ≤ 20 min + 敲 1 h | **阅读官方文档 20～30 min + 敲 1 h** |
| 周六 | 项目 2～3 h | 不变（项目是纯文字路线唯一的综合训练） |
| 每天验收 | — | 新增：**当日代码 ≥ 40 行，含至少 1 道 CodingBat** |
