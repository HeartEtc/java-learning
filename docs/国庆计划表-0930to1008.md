**要定的设计问题**（各写一句理由）：

| 问题 | 提示 |
|---|---|
| 金额用什么类型？ | **不能用 `double`**（`0.1 + 0.2 != 0.3`）→ `BigDecimal` 或"以分为单位的整数" |
| 分类用什么？ | 字符串？还是**枚举**？（枚举能防止拼写错误、能遍历） |
| 数据怎么存？ | CSV 还是 JSON？（P1 没做过文件读写，CSV 更简单） |
| 类怎么分？ | `Record`（一条记录）、`Ledger`（账本，持有记录）、`Main`（菜单）、`FileStorage`（读写文件） |
| 文件读写的接口怎么设计？ | `load()` / `save()` 放哪一层？`Ledger` 自己读写，还是抽一个单独的类？ |

**交付物**：`docs/P2-设计.md`（类清单 + 字段 + 每个决策的理由）
