## 项目

### P1 图书管理系统（控制台）

练手项目，目标是走通「类设计 → 继承/多态 → 自定义异常 → 菜单交互」这条链路。

- **类设计**：`Book`（书目）、`User`（抽象类，含 `Reader` / `Admin`）、`Loan`（借阅记录）、`Library`（核心逻辑）、`Main`（菜单入口）
- **用到的技术**：抽象类与抽象方法、多态、封装与构造器校验、自定义异常、`java.time.LocalDate`
- **已知简化**：内部数据用数组存储（容量在构造器传入），待学完集合框架后重写

运行方式：在 IDEA 中运行 `com.example.library.Main`。
